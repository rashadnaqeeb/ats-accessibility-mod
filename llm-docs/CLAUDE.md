# llm-docs

Reference documentation for the Against the Storm accessibility mod. These documents provide detailed context beyond what's in the root CLAUDE.md.

## Contents

- **game-api-reference.md** — Catalog of game types, services, and members accessed via reflection. Organized by system (controllers, buildings, recipes, orders, trade, villagers, etc.). Use this to find game APIs when adding new features or debugging reflection access.

- **game-overview.md** — Against the Storm game mechanics reference: grid types, core mechanics (reputation/impatience, resources, buildings, recipes, workers, seasons), control scheme, game screens, UI elements, BepInEx modding setup, and accessibility coverage.

- **mod-coverage-map.md** — Complete map of what the mod currently covers: all overlays (35), handler priority chain (53 handlers), building navigators (14), information panels (15), popup routing order, event announcements, and scene coverage.
